## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight inline padding (e.g. center-disc py-3) |
| sm | 8px | Compact element spacing (gap-2, gap-3 within stat rows) |
| md | 16px | Default element spacing (px-4, gap-4) |
| lg | 24px | Section padding (px-6, py-6, gap-6) |
| xl | 32px | Layout gaps (gap-8) |
| 2xl | 48px | Large layout gaps (gap-12) |

Exceptions:
- Pad border: `border-[8px]` (8px — on scale)
- Board outer border: `border-[12px]` (12px — intentional for physical-board aesthetic, not a spacing token)
- Center disc inset: `inset-[26%]` (proportional, not a spacing token)
- Touch target minimum: pad buttons occupy 50% of board square — well above 44px minimum on any screen size this game targets

## Typography

All text uses the system default sans-serif font. No custom font is loaded.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 30px / 36px (sm) | 600 semibold | 1.2 | Game title "Simon Memory" (`text-3xl sm:text-4xl font-semibold`) |
| Heading | 24px | 600 semibold | 1.2 | Section or card headings |
| Body | 14px / 16px (sm) | 400 regular | 1.5 | Subtitle, status message, how-to-play (`text-sm sm:text-base`) |
| Label | 12px | 600 semibold | 1.0 | Stat labels, section headers, center-disc indicator text (WATCH/REPEAT/IDLE), all supporting decorative text (`text-xs font-semibold`) |

Only two non-decorative weights are used: **400 regular** (body text) and **600 semibold** (all headings, labels, and supporting text). The difference between 500 medium and 600 semibold is imperceptible at 12px; Label role uses 600 semibold throughout.

**Decorative exception — not part of the type scale:**
- Weight 900 black (`font-black`) is used exclusively for the center-disc "SIMON" wordmark. This is a fully decorative logotype treatment, not a typographic role. It does not count against the 2-weight limit.

## Pad Visual State Contract

This section is the authoritative specification for the pad glow bug fix (D-01, D-02, D-03).

### States

| Pad State | Condition | Visual Classes Applied |
|-----------|-----------|----------------------|
| **Active** (sequence playback or user tap) | `activePad === pad.id` | `{pad.glowClass} scale-[1.03] brightness-125` + base color — NO opacity reduction, NO `disabled` attribute |
| **Interactive** (user's turn, not active) | `isUserTurn && activePad !== pad.id` | `cursor-pointer hover:brightness-110` + normal shadow — full brightness |
| **Idle** (not user turn, not active) | `isDisabled && activePad !== pad.id` | `cursor-not-allowed` only — **NO `opacity-40`**, full brightness maintained |

### Class Assembly Rule (replaces current buggy logic)

Current (buggy):
```
interactiveClasses = isDisabled ? 'cursor-not-allowed opacity-40' : 'cursor-pointer hover:brightness-110'
disabled={isDisabled}
```

Required fix:
```
interactiveClasses = isDisabled && !isActive
  ? 'cursor-not-allowed'
  : !isDisabled
    ? 'cursor-pointer hover:brightness-110'
    : ''   // isDisabled && isActive — no cursor class, pad is being shown active

disabled={isDisabled && !isActive}
```

Key rule: `opacity-40` must **never** appear on any pad in any state.

### Focus Ring

Focus-visible ring retained on all pads for keyboard/accessibility: `focus-visible:ring-4 focus-visible:ring-slate-100/70 focus-visible:ring-offset-2 focus-visible:ring-offset-black`

## Touch and Viewport Contract

### Viewport Meta Tag

Replace existing `<meta name="viewport">` content in `index.html` with:

```
width=device-width, initial-scale=1.0, user-scalable=no, viewport-fit=cover
```

- `user-scalable=no` — prevents pinch-zoom during pad taps (eliminates accidental zoom on double-tap)
- `viewport-fit=cover` — fills safe area on notched/rounded-corner Android devices

### Touch Action

Add `style={{ touchAction: 'manipulation' }}` as an inline style to each pad `<button>` element.

- Tailwind CSS v4 has no built-in `touch-manipulation` utility — inline style is the correct approach
- `touch-action: manipulation` eliminates the 300ms tap delay on Android Chrome without disabling scroll
- Applied to pad buttons only; not required on Start/Reset buttons (no timing sensitivity)

## Copywriting Contract

All copy is sourced from `App.tsx` state strings. No copy changes are made in Phase 1.

### Status Messages (displayed in the status card)

| Trigger | Exact Copy |
|---------|-----------|
| Initial load / after reset | `Press Start to begin.` |
| Sequence playback starts | `Watch the pattern...` |
| User's turn begins | `Your turn – repeat the sequence.` |
| Correct tap, sequence not complete | `Good! Keep going...` |
| Wrong tap | `Oops! Wrong move. Sequence reset.` |
| Round complete, streak continues | `Nice! Get ready for the next round...` |
| Streak milestone (every 5 in a row) | `Amazing! {N} sequences in a row!` |

### Button Labels

| Button | Label | State Variants |
|--------|-------|---------------|
| Primary CTA | `Start Game` | When `sequence.length === 0` |
| Primary CTA | `Replay / Next Round` | When `sequence.length > 0` |
| Secondary | `Reset` | Always "Reset" — disabled when game not active |

### Stat Labels

| Stat | Label |
|------|-------|
| Round counter | `Round` |
| Streak counter | `Streak` |
| Best streak (header) | `Best Streak` |
| Best streak (sidebar card) | `Best Streak` |
| Mode card | `Mode` |
| Mode value | `Classic single-player` |
| How to play header | `How to play` |

### Empty State

There is no empty state UI in this game. The idle state is the pre-game state, conveyed by status message `Press Start to begin.` and a disabled Reset button.

### Error State

Wrong input during user turn: status message `Oops! Wrong move. Sequence reset.` + low buzzer tone (120Hz, 500ms). No visual color change to UI chrome. Game auto-resets after 900ms delay. No confirmation dialog or modal.

### Destructive Actions

`Reset` button is the only destructive action. No confirmation dialog — direct reset. The button is disabled when there is nothing to reset (`sequence.length === 0 && !isPlayingSequence && !isUserTurn`), preventing accidental activation.
