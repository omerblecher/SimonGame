  <action>
    Create scripts/generate_icon.py (new file; scripts/ directory does not exist yet — create it).

    Script must:
    - Import from PIL: Image, ImageDraw
    - Import os
    - Define constants: BACKGROUND = '#0f172a', COLORS = {'TL': '#4ade80', 'TR': '#f87171', 'BL': '#fbbf24', 'BR': '#60a5fa'}
    - Define MIPMAP_SIZES dict: {'mipmap-mdpi': 48, 'mipmap-hdpi': 72, 'mipmap-xhdpi': 96, 'mipmap-xxhdpi': 144, 'mipmap-xxxhdpi': 192}
    - Define RES_DIR = 'android/app/src/main/res'
    - Define ASSETS_DIR = 'assets/icons'
    - Define make_simon_icon(size: int) -> Image.Image: creates RGBA image, draws 4 rectangles with proportional gap (gap = max(2, size // 48)), half = size // 2; TL fills [gap, gap, half-gap, half-gap], TR fills [half+gap, gap, size-gap, half-gap], BL fills [gap, half+gap, half-gap, size-gap], BR fills [half+gap, half+gap, size-gap, size-gap]
    - Define make_round_icon(size: int) -> Image.Image: calls make_simon_icon(size), creates L-mode mask with ellipse fill, calls img.putalpha(mask)
    - Main generation block (os.makedirs for ASSETS_DIR):
      * Store listing icon: make_simon_icon(512).convert('RGB').save(f'{ASSETS_DIR}/simon-icon-512.png')
      * Feature graphic: construct a native 1024x500 Image.new('RGB', (1024, 500), BACKGROUND), use ImageDraw to draw 4 rectangles with gap=10, half_w=512, half_h=250; save as f'{ASSETS_DIR}/feature-graphic.png' (RGB, no alpha)
      * Mipmap loop: for each (mipmap_dir, size) in MIPMAP_SIZES.items(): os.makedirs the output dir, save make_simon_icon(size).convert('RGB') as ic_launcher.png, save make_round_icon(size) as ic_launcher_round.png (RGBA, keep alpha)
    - Print 'Icon generation complete.' at the end

    Do NOT use LANCZOS resizing — generate directly at each target size.
    Do NOT use ImageFont — no text overlay needed on any asset (per A5 assumption).
  </action>
