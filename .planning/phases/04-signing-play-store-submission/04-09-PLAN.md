  <how-to-verify>
    Step 1 — Verify no remaining action items:
      Go to the app Dashboard in Play Console (https://play.google.com/console)
      Check for any incomplete "Tasks" or required items shown with red indicators
      Common remaining items at this stage: Data Safety form finalization, Privacy policy URL
      Resolve any before proceeding.

    Step 2 — Create a Production release:
      Navigate to: Release > Production > Create new release
      Click "Add from library" (the AAB uploaded in Plan 04-08 is already available — reuse it)
      Select version 1 (1.0)
      Click Next

    Step 3 — Review the rollout:
      Choose rollout percentage: 100% (full production release)
      Alternative: 20% staged rollout (Play Console monitors crash rate; can halt if issues found)
      Recommendation: 100% for a new app with no existing users

    Step 4 — Review and submit:
      Review all sections (store listing, content rating, pricing, distribution)
      Click "Review release"
      If any required items are flagged, complete them and return
      Click "Start rollout to Production"
      Confirm the dialog

    Step 5 — Verify submission status:
      Dashboard should show: "Under review" or "In review"
      Review typically takes 1-7 business days for a new app

    Step 6 — Confirm:
      Play Console > Dashboard shows a banner like "Your app is being reviewed"
      or: Status column shows "In review" for the production release
  </how-to-verify>
