## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dist/ → gradlew bundleRelease | Test banner ID must not be present in dist/ when bundleRelease is run |
| AAB → Play Console upload | AAB must be signed with the release keystore; Play App Signing re-signs before distribution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-15 | Repudiation | Test banner ID in release AAB | mitigate | grep dist/ for test ID before sync (acceptance criterion in Task 1) |
| T-04-16 | Denial of Service | JAVA_HOME pointing to Java 8 | mitigate | Explicit JAVA_HOME override in Task 1 step 1; common pitfall documented in action |
| T-04-17 | Tampering | Release AAB file integrity | accept | Signed by our keystore; Play App Signing adds Google's layer; AAB hash shown in Play Console |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan |
</threat_model>
