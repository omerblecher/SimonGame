## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering | android:screenOrientation value | mitigate | Verify exact string "portrait" via Select-String after edit; wrong value (e.g., "fullUser") would allow landscape |
| T-02-04 | Denial of Service | npm run build failure | mitigate | Stop pipeline at Step 1 on non-zero exit; do not sync a broken build |
| T-02-05 | Information Disclosure | dist/ contains source maps | accept | Development build only; no PII in source maps; release signing (Phase 4) will use minified production build |
| T-02-SC | Tampering | npx cap sync android | mitigate | Cap sync only reads from local dist/ and node_modules — no network fetch during sync |
</threat_model>
